# sai-shop

## Editable Thermal Receipt Template

A responsive browser-only receipt editor inspired by the supplied Sai Kirana Store sample.

### Open it
Open `receipt-template/index.html` in a browser, or enable GitHub Pages for this repository and visit:
`https://hellohacker143.github.io/sai-shop/receipt-template/`

### Features
- Change the shop name, bill number, date, time, cashier, discount, thank-you message and footer.
- Edit product names, quantities and rates.
- Add product rows or remove rows.
- Automatic line amounts, subtotal, total quantity and grand total.
- Live thermal receipt preview.
- Print on 58 mm / 80 mm thermal printers using the browser print dialog, or choose Save as PDF.
- No server, database, account or external library required.

### Notes
The supplied example contains some quantities/rates/amounts that do not reconcile. This template calculates each amount as quantity × rate, and recalculates subtotal and grand total automatically.
